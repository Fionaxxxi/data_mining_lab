# 实验七 Web 交互入口

双击项目根目录的 `启动网页.cmd`；也可在项目根目录执行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\start_web.ps1`。浏览器会打开 `http://127.0.0.1:8767/`；关闭服务请在启动它的终端按 `Ctrl+C`。

默认使用离线规则，不需要密钥、模型文件或联网。页面的规划表单会调用本地 `src/lab7/agent.py`，从实验六图谱查询黄山、九寨沟、张家界的路线和条件建议，显示实际方案、工具轨迹与证据编号。未知景区和信息不足由 Agent 返回说明或追问。图谱搜索读取完整 471 节点、629 关系数据，并在画布中展示匹配节点的局部关系。

模型是可选项。规划区点击“运行模式与模型设置”，可选择“离线规则”或“模型辅助”，填写 Base URL、Model Name、API Key 后保存。设置写入项目根目录被 Git 忽略的 `.env`，后续规划立即生效。页面只显示“密钥已配置”，不会读取或回显密钥；留空表示保留已存密钥，勾选“清除已保存的密钥”可删除。模型模式需要三项齐全；离线模式无需密钥。接口地址填写基础地址，程序会追加 `/chat/completions`。服务器只绑定本机 `127.0.0.1`，设置请求要求同源页面和本次服务启动时生成的令牌。模型请求失败时 Agent 会回退规则版；结果区会按实际成功响应情况显示“模型参与”或“规则回退”。也可直接参考 `.env.example` 手动配置。

本网页是本机部署，绑定 `127.0.0.1:8767`，不会公开发布到互联网。照片和在线字体来自外部地址，断网时文字和规划功能仍可用，照片可能无法加载。景区当前开放、票价与实际通行情况未核验。
