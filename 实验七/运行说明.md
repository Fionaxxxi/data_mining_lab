# 实验七交付说明（旅游规划 Agent）

本文件夹位于项目目录内，可用项目专用虚拟环境独立运行核心测试。事实源为实验六图谱，实验七不重建图谱、不重跑前序实验、不新增抓取。

## 目录结构

```
实验七\
├─ 实验七报告.md              主报告（评分对照、失败记录、局限）
├─ 实验总结反思.md            只含实验七：问题及解决办法、局限、突破点
├─ docs\实验七执行计划.md      实施计划与验收标准
├─ src\lab7\                  全部代码
│  ├─ graph_tool.py           图谱只读查询工具 knowledge_graph_query
│  ├─ intent.py               意图解析（规则版）
│  ├─ llm.py                  OpenAI 兼容后端 + 离线回退
│  ├─ planner.py              时段消歧、时序修复、择优、两日切分
│  ├─ agent.py                ReAct 编排与轨迹
│  ├─ cli.py                  单次/交互/JSON 入口
│  ├─ tests.py                8 例场景测试
│  ├─ figures.py              架构图、轨迹图、时段图
│  ├─ console_shot.py         运行输出截图（由真实 stdout 渲染）
│  └─ check.py                30 项验收
├─ data\lab7\                 解析规则、LLM 提示模板、8 例场景期望
├─ outputs\lab7\              结果：测试、轨迹、查询参数、验收、配图
├─ outputs\lab6\              复用所需最小输入：graph.json、evidence.jsonl、stats.json
└─ 数据挖掘实验七_旅游规划Agent_全工程.zip   含 lab1–7 的完整仓库副本
```

`outputs\lab6\` 只保留运行实验七所需的三份文件，不是实验六的全部产物；若要重跑实验六，请用压缩包中的完整工程。

## 运行方式

从项目根目录一键复跑：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1 -Lab 7
```

或进入实验七目录，分别运行：

```powershell
Set-Location 'D:\uniproject\data_mining\data_mining_lab-main\data_mining_lab-main\实验七'
$env:PYTHONUTF8 = '1'
$py = 'D:\uniproject\data_mining\.venv\Scripts\python.exe'

# 单次提问（带 ReAct 轨迹）
& $py src\lab7\cli.py --query "带老人去黄山玩一天，希望行程轻松平缓" --trace

# 交互模式
& $py src\lab7\cli.py --interactive

# 复跑核心验证（check.py 读取 tests.py 更新的结果和已有 SVG 图件）
& $py src\lab7\tests.py
& $py src\lab7\check.py
& $py src\lab7\console_svg.py  # 从真实终端输出文本生成报告用 SVG 摘录
```

核心 Agent、测试和验收仅用标准库。需要重新绘制图件时，在项目虚拟环境安装 `matplotlib` 后运行 `& $py src\lab7\figures.py`；需要重绘两张控制台图片时安装 `Pillow` 后运行 `& $py src\lab7\console_shot.py`。本次环境无法连接包索引，沿用仓库已有 SVG 图件进行验证。根目录 `run.ps1 -Lab 7` 已接入核心测试与验收。

## 已验证结果

- 8 例场景：期望核对失败 0 例，单例工具调用最多 3 次；
- 30 项验收：30/30 通过，退出码 0；其中新增 1 项为本地模拟 LLM 请求/响应链路检查，不代表真实 API 已连通；
- 引用证据 46 条，缺失 0 条；来源为实验三路线 30 条、实验五建议 16 条；
- 方案景点全部可回指实验六步骤；同一离线输入两次运行结果一致；
- 图件：三张架构/轨迹/时段 SVG 与两张本次终端输出摘录 SVG 可直接插入报告；仓库的旧 PNG 为历史运行图。

## 已知限制

1. 无 `OPENAI_API_KEY`，8 例场景均为 `provider=offline-rules`；在线调用链经过本地模拟响应验证，真实 API 尚未验证。
2. 图谱仅三景区各一条官方整理路线，两日方案是时段切分，不是官方两日线路。
3. 图谱不含坡度、海拔、步行距离与索道运力，老人/亲子的体力可行性无法真正评估。
4. 引用未覆盖实验二实体记录与实验四共指记录。
5. 票价、开放时间、通行状态一律不回答，方案末尾均声明“未核验”。
