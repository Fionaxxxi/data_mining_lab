# 实验七交付说明（旅游规划 Agent）

本文件夹位于项目目录内，可用项目专用虚拟环境独立运行核心测试。事实源为实验六图谱，实验七不重建图谱、不重跑前序实验、不新增抓取。

## 目录结构

```
实验七\
├─ .env                       本机 LLM 配置（已加入 Git 忽略）
├─ .env.example               配置模板，不含真实密钥
├─ 测试集说明.md               用例范围、运行方式和逐项预期
├─ 实验七报告.md              主报告（评分对照、失败记录、局限）
├─ 实验总结反思.md            只含实验七：问题及解决办法、局限、突破点
├─ docs\实验七执行计划.md      实施计划与验收标准
├─ src\lab7\                  全部代码
│  ├─ graph_tool.py           图谱只读查询工具 knowledge_graph_query
│  ├─ intent.py               意图解析（规则版）
│  ├─ llm.py                  OpenAI 兼容后端 + 离线回退
│  ├─ planner.py              图谱路线整理、LLM 分日提案校验、规则回退
│  ├─ agent.py                ReAct 编排与轨迹
│  ├─ cli.py                  单次/交互/JSON 入口
│  ├─ tests.py                8 例场景测试
│  ├─ online_tests.py         8 例真实 LLM 在线测试

├─ data\lab7\                 解析规则、LLM 提示模板、8 例场景期望
│  └─ test_catalog.json       63 项测试登记与预期
```

`outputs\lab6\` 只保留运行实验七所需的三份文件，不是实验六的全部产物。旧版完整工程 ZIP 已按用户要求删除。

## 运行方式

### 配置真实 LLM

在本目录编辑 `.env`，填写服务商发放的 `OPENAI_API_KEY`、兼容接口基础地址 `OPENAI_BASE_URL` 和可用模型名 `OPENAI_MODEL`。模板见 `.env.example`（默认示例为火山方舟）；`.env` 已加入 Git 忽略规则，不会随仓库提交。程序启动时自动读取它；当前 PowerShell 会话中已经设置的同名环境变量优先级更高。接口地址填写基础地址（例如 `https://ark.cn-beijing.volces.com/api/v3`），程序会追加 `/chat/completions`。

配置完成后，从本目录发起单次真实模型调用：

```powershell
& 'D:\miniconda3\envs\dm_scenic_lab\python.exe' src\lab7\cli.py --query "带老人去黄山玩一天，希望行程轻松平缓" --trace
```

成功时轨迹会显示配置的 `openai-compatible:<模型名>`、HTTP 请求/成功响应数以及回退数。真实调用通过条件见 [测试集说明](测试集说明.md)；若请求失败，程序会显示错误阶段并回退到规则生成器。

从项目根目录一键复跑：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1 -Lab 7
```

执行完整在线测试集（先跑离线回归，再真实调用当前配置模型 8 例）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1 -Lab 7 -Online
```

在线测试串行执行、不自动重试；动态决策的请求次数取决于问题和观察轮次，本轮 8 例共尝试 35 次，后续运行次数可能变化，调用可能产生费用。结果写在 `outputs\lab7\online_test_results.json` 和 `online_test_run.log`。只给 `-Online` 且 Lab 不是 7 会报错；不加 `-Online` 的常规命令不会联网。

或进入实验七目录，分别运行：

```powershell
Set-Location 'D:\data_lab\scenic_lab1\实验七'
$env:PYTHONUTF8 = '1'
$py = 'D:\miniconda3\envs\dm_scenic_lab\python.exe'

# 单次提问（带 ReAct 轨迹）
& $py src\lab7\cli.py --query "带老人去黄山玩一天，希望行程轻松平缓" --trace

# 交互模式
& $py src\lab7\cli.py --interactive

# 复跑核心验证（check.py 读取 tests.py 更新的结果和已有 SVG 图件）
& $py src\lab7\tests.py
& $py src\lab7\check.py
& $py src\lab7\console_svg.py  # 从真实终端输出文本生成报告用 SVG 摘录
```

核心 Agent、测试和验收仅用标准库。需要重新绘制图件时，在项目虚拟环境安装 `matplotlib` 后运行 `& $py src\lab7\figures.py`；需要重绘两张控制台图片时安装 `Pillow` 后运行 `& $py src\lab7\console_shot.py`。本次环境无法连接包索引，沿用仓库已有 SVG 图件进行验证。根目录 `run.ps1 -Lab 7` 已接入核心测试与验收。

- 自动验收：最新 47/47 通过，退出码 0；LLM 决策和异常路径使用本地模拟，真实模型决策表现以下方在线运行记录为准；
- 在线验收：旧版规划链路历史结果 8/8 通过，不代表动态工具决策版。动态决策版最新完整运行有 23/35 次成功响应、20 次回退，8/8 未通过；修复意图字段校验和动作参数提示后的下一轮按用户要求中止，未形成完整结果。最新完整记录为 `outputs\lab7\online_runs\20261113_182747.json/.log`；
- 引用证据 46 条，缺失 0 条；来源为实验三路线 30 条、实验五建议 16 条；
- 方案景点全部可回指实验六步骤；同一离线输入两次运行结果一致；
- 图件：三张架构/轨迹/时段 SVG 与两张本次终端输出摘录 SVG 可直接插入报告；仓库的旧 PNG 为历史运行图。

## 已知限制

1. 默认场景回归强制使用 `provider=offline-rules`；完整在线场景由显式 `-Online` 单独执行。模型对多场景的泛化仍需按在线结果判断。
2. 图谱仅三景区各一条官方整理路线，两日方案是时段切分，不是官方两日线路。
3. 图谱不含坡度、海拔、步行距离与索道运力，老人/亲子的体力可行性无法真正评估。
4. 引用未覆盖实验二实体记录与实验四共指记录。
5. 票价、开放时间、通行状态一律不回答，方案末尾均声明“未核验”。
